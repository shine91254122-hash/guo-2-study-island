# 國二科目學習島 · 3D 翰林探索版

公開網站：[進入國二學習島](https://shine91254122-hash.github.io/guo-2-study-island/)

11 座真正 3D 島嶼，各有專屬人物與學科場景，可拖曳旋轉、縮放及近看人物。

- 50 個翰林八上主科章節：國文、英語、數學、理化、地理、歷史、公民。
- 12 個自編延伸任務：藝術、科技、健體、綜合。
- 每個航點包含自編重點、例子、小測驗及筆記。
- 互動實驗：波動與聲音、光的折射、畢氏定理。
- 學習進度與筆記保存在目前瀏覽器，可在航海日誌匯出或匯入 JSON。

## 單機使用

目前 `index.html` 已包含樣式、3D 引擎、課程及互動程式。下載這個檔案並以支援 WebGL 的瀏覽器開啟即可離線使用，不需要後端服務。Three.js 的 MIT 授權隨檔保留。

## 教材範圍

先建置八年級上學期。國文依 115 年翰林官方目錄；數學依官方八上網站；理化與社會依公開翰林目錄（112、113 年）；英語依學校公開課程計畫並以中文主題摘要呈現。來源連結可在網站的「章節來源與版本說明」查看。

藝術、科技、健體、綜合為自編延伸任務，並非翰林逐課目錄。學習重點、例子及題目均為自編內容；請搭配學校實際採用課本核對年度差異。

GitHub Pages 從 `main` 分支根目錄發布，首頁已更新為新版 3D 學習島。
