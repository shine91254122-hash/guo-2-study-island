# 國二學習島｜單機版

這是一個不需要後端、不需要安裝套件的單機版學習地圖。直接雙擊 `index.html` 即可使用。

## 已包含

- 國文、數學、英文、自然、社會、健體、科技、藝術 8 座學習島
- 翰林、康軒、南一版本切換
- 國二上學期範例章節架構
- 學科總覽地圖、章節索引、搜尋與分類篩選
- 章節完成勾選與學習日誌
- 進度使用瀏覽器 `localStorage` 儲存在本機，不會上傳
- 夜航／日光顯示模式與響應式手機版

## 內容調整

所有課程資料集中在 `app.js` 最前面的 `subjectData`，可以直接修改出版社、章節名稱、描述、標籤與顏色。若要改成學校實際採用版本，只需要調整各科的 `defaultVersion` 與 `versions` 內容。

本頁只放課本章節名稱與自編導讀，不含課本內文；實際章節順序可能因年度、冊次與學校選用版本不同而需要微調。
